# MD Peek

Лёгкий нативный Markdown-просмотрщик для macOS 14+. Приложение открывает Markdown только для чтения.

## Сборка и установка

Нужны Xcode Command Line Tools и Swift. В корне проекта выполните:

```sh
./scripts/build.sh
cp -R "build/MD Peek.app" /Applications/
```

Чтобы назначить приложение обработчиком `.md`: в Finder выберите Markdown-файл → **Файл → Свойства** → **Открывать в программе** → MD Peek → **Изменить все**. Для `.markdown` действие можно повторить отдельно.

## Возможности

- Отдельное окно на документ; Finder, `⌘O`, запуск через `open -a`.
- Заголовки, GFM-таблицы, списки, цитаты, ссылки, изображения, горизонтальные линии и блоки кода через MarkdownUI.
- Относительные изображения ищутся от папки документа.
- Светлая/тёмная системная тема, центрированная колонка до 760 pt, нативная прокрутка и выделение.
- `⌘+`, `⌘−`, `⌘0`, `⌘R`; масштаб сохраняется между запусками.
- Обнаружение изменений и атомарной замены файла с перечитыванием.
- Никаких HTML/WebView, выполнения кода или записи в Markdown-файлы.

## Проверка

Тестовый файл находится в `Tests/Fixtures/elements.md`. Сборка выполняется Swift Package Manager, затем приложение упаковывается в `.app` и подписывается ad-hoc для локального использования.
